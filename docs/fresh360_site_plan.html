Section 6
Tech Stack
Every choice made for performance, minimal bundle size, and future CMS portability.
Framework
Next.js 14+ (App Router)
SSG for product pages, built-in API routes, image optimisation, metadata API
Styling
Tailwind CSS 3
Utility-first. Zero runtime CSS. Smallest possible CSS output via PurgeCSS
Components
shadcn/ui
Radix primitives, copy-paste pattern, zero bundle bloat, accessible out of the box
Icons
Lucide React
Consistent stroke-based set, tree-shakeable, no icon font overhead
Animations
CSS transitions only
No Framer Motion unless strictly needed. Intersection Observer for scroll reveals
Data Layer
Local JSON → lib/ helpers
All data access through typed TS functions. Drop-in CMS swap with zero component changes
Form Email
Resend API
Simplest reliable email delivery from Next.js API routes. Free tier covers launch volume
Images
next/image
Automatic WebP conversion, lazy loading, blur placeholder, responsive srcset
Hosting
Vercel
Native Next.js support, free SSL, global CDN, automatic previews per PR
Analytics
GA4 via @next/third-parties
Env-gated. Zero blocking scripts. Swap to Plausible/Fathom if privacy is priority
SEO
Metadata API + next-sitemap
Type-safe metadata per page. Sitemap/robots.txt auto-generated on build
Validation
Zod
Schema validation for contact form server-side. Shared types with client if needed

Section 9
Build Timeline
6 phases. Total: ~6 weeks from kickoff to production. Assumes client provides assets by end of Week 1.
1
Week 1
Setup & Foundation
  • Next.js 14 + Tailwind + shadcn scaffold
  • Folder structure, TypeScript interfaces
  • JSON population: Juicera products + brands
  • lib/ helper functions + Zod schemas
  • Vercel project + domain + env setup
2
Weeks 2–3
Core Pages
  • Homepage (all 7 zones)
  • Product Listing + Product Detail pages
  • Juicera Brand page
  • Design system: colours, typography, shared components
  • Global Nav + Footer + WhatsApp float
3
Week 4
Remaining Pages & Fuzzy / Refrizz
  • About, Process, Contact pages
  • Contact API route (Resend email)
  • Fuzzy + Refrizz brand pages + product data
  • 404 page
4
Week 5
QA, Polish & SEO
  • Mobile QA: 375px, 390px, 414px breakpoints
  • Lighthouse audit → hit all perf targets
  • Accessibility: axe-core, keyboard nav, focus states
  • SEO: Metadata API per page, OG images, sitemap, robots
  • Cross-browser: Chrome, Safari (iOS), Firefox
5
Week 6
Launch
  • Vercel production deploy + custom domain + SSL
  • GA4 tracking verification
  • Post-launch smoke test (all routes, form, WhatsApp links)
  • Hand off: CMS migration guide + content update docs
